# Kaibo Wang — academicpages site

Personal homepage based on [academicpages](https://github.com/academicpages/academicpages.github.io). Content is taken from the existing CVs (education, two papers, projects, internship).

## Publish on GitHub Pages

1. Create a GitHub repository named `YOUR_USERNAME.github.io`.
2. In `_config.yml`, set `url` to `https://YOUR_USERNAME.github.io` and `repository` to `YOUR_USERNAME/YOUR_USERNAME.github.io`. Optionally fill in `author.github`.
3. Replace `images/profile.png` with your photo.
4. Push this `website/` folder as the **root** of that repository (not as a subfolder).
5. GitHub → Settings → Pages → Source: Deploy from a branch → `main` / `/ (root)`.

The site will be at `https://YOUR_USERNAME.github.io`.

Local preview (needs Ruby / Jekyll):

```bash
bundle install
bundle exec jekyll serve
```
